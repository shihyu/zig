枚舉 ​

枚舉常用於表示一個有限集合的成員，或對特定類型的對象進行分類。

枚舉是一種相對簡單但用途廣泛的類型。

聲明枚舉 ​

我們可以通過 enum 關鍵字輕鬆地聲明和使用枚舉：

zig
const Type = enum {
    ok,
    not_ok,
};

const c = Type.ok;

同時，Zig 還允許我們訪問和操作枚舉的標記值：

zig
// 指定枚举的标记类型
// 现在我们可以在 u2 和 Value 这个枚举类型之中任意切换了
const Value = enum(u2) {
    zero,
    one,
    two,
};

在此基礎上，我們還可以覆蓋枚舉的標記值：

zig
const Value2 = enum(u32) {
    hundred = 100,
    thousand = 1000,
    million = 1000000,
};

// 覆盖部分值
const Value3 = enum(u4) {
    a,
    b = 8,
    c,
    d = 4,
    e,
};

🅿️ 提示

枚舉類型支持使用 if 和 switch 進行匹配，具體細節請參見相應章節。

枚舉方法 ​

是的，枚舉也可以擁有方法。實際上，枚舉在 Zig 中是一種特殊的命名空間（可以看作一種特殊的 struct）。

zig
const Suit = enum {
    clubs,
    spades,
    diamonds,
    hearts,

    pub fn isClubs(self: Suit) bool {
        return self == Suit.clubs;
    }
};

枚舉大小 ​

需要注意的是，Zig 編譯器會嚴格計算枚舉的大小。例如，前面示例中的 Type 枚舉，其大小等效於 u1。

以下示例中，我們使用了內建函數 @typeInfo 和 @tagName 來獲取枚舉的大小和對應的標籤名稱（tag name）：

zig
const std = @import("std");
const expect = std.testing.expect;
const mem = std.mem;

const Small = enum {
    one,
    two,
    three,
    four,
};

pub fn main() !void {
    try expect(@typeInfo(Small).@"enum".tag_type == u2);
    try expect(@typeInfo(Small).@"enum".fields.len == 4);
    try expect(mem.eql(u8, @typeInfo(Small).@"enum".fields[1].name, "two"));
    try expect(mem.eql(u8, @tagName(Small.three), "three"));
}

枚舉推斷 ​

枚舉也支持類型推斷（通過結果位置語義），即在已知枚舉類型的情況下，可以僅使用字段名來指定枚舉值：

zig
const Color = enum {
    auto,
    off,
    on,
};

pub fn main() !void {
    const color1: Color = .auto; // 此处枚举进行了自动推断
    const color2 = Color.auto;
    _ = (color1 == color2); // 这里比较的结果是 true
}

非詳盡枚舉 ​

Zig 允許我們定義非詳盡枚舉，即在定義時無需列出所有可能的成員。未列出的成員可以使用 _ 來表示。由於存在未列出的成員，編譯器無法自動推斷枚舉的大小，因此必須顯式指定其底層類型。

zig
const Number = enum(u8) {
    one,
    two,
    three,
    _,
};

const number = Number.one;
const result = switch (number) {
    .one => true,
    .two, .three => false,
    _ => false,
};
// result 是 true

const is_one = switch (number) {
    .one => true,
    else => false,
};
// is_one 也是true

🅿️ 提示

@enumFromInt 能夠將整數轉換為枚舉值。但需要注意，如果所選枚舉類型中沒有表示該整數的值，就會導致未定義行為。

如果目標枚舉類型是非詳盡枚舉，那麼除了涉及 @intCast 相關的安全檢查之外，@enumFromInt 始終能夠得到有效的枚舉值。

zig
const Color = enum(u4) {
    red,
    green,
    blue,
    _,
};

// 明确列出的枚举值
const blue: Color = @enumFromInt(2);
try expect(blue == .blue);

// 未列出的枚举值：8 在 u4 的范围内（0~15）
const yellow: Color = @enumFromInt(8);
try expect(@TypeOf(yellow) == Color);
try expect(@intFromEnum(yellow) == 8);

// 42 超出了 u4 的范围，会触发未定义行为
// const ub: Color = @enumFromInt(42);

EnumLiteral ​

🅿️ 提示

此部分內容並非初學者需要掌握的內容，它涉及到 Zig 的類型系統和編譯期反射，可以暫且跳過！

Zig 還包含一個特殊的類型 EnumLiteral，它是 std.builtin.Type 的一部分。

我們可以稱之為“枚舉字面量”。它是一個與 enum 完全不同的類型。可以查看 Zig 類型系統對 enum 的定義，其中並不包含 EnumLiteral。

它的具體用法如下：

zig
// 使用内建函数 @Type 构造出一个 EnumLiteral 类型
// 这是目前官方文档中的使用方案
const EnumLiteral: type = @Type(.enum_literal);

// 定义一个常量 enum_literal，它的类型为 EnumLiteral，并赋值为 “.kkk”
const enum_literal: EnumLiteral = .kkk;

// 使用内建函数 @tagName 获取 enum_literal 的 tag name，并进行打印
std.debug.print("enum_literal is {s}", .{@tagName(enum_literal)});

注意：此類型常用於函數參數。

extern ​

注意，我們通常不直接對枚舉使用 extern 關鍵字。

默認情況下，Zig 不保證枚舉與 C ABI 兼容，但我們可以通過指定其標記類型來確保兼容性：

zig
const Foo = enum(c_int) { a, b, c };
