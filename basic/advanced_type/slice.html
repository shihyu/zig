切片 ​

切片與數組非常相似。在實際應用中，由於其靈活性，切片的使用比數組更普遍。

你可以從數組、其他切片或數組指針創建新的切片。

接下來，我們來演示如何使用切片：

zig
var array = [_]i32{ 1, 2, 3, 4 };

const len: usize = 3;
const slice: []i32 = array[0..len];

for (slice, 0..) |ele, index| {
    print("第{}个元素为：{}\n", .{ index + 1, ele });
}
print("slice 类型为{}\n", .{@TypeOf(slice)});

const slice_2: []i32 = array[0..array.len];
print("slice_2 类型为{}\n", .{@TypeOf(slice_2)});
zig
const print = @import("std").debug.print;

pub fn main() void {
    var array = [_]i32{ 1, 2, 3, 4 };

    const len: usize = 3;
    const slice: []i32 = array[0..len];

    for (slice, 0..) |ele, index| {
        print("第{}个元素为：{}\n", .{ index + 1, ele });
    }
    print("slice 类型为{}\n", .{@TypeOf(slice)});

    const slice_2: []i32 = array[0..array.len];
    print("slice_2 类型为{}\n", .{@TypeOf(slice_2)});
}

打印結果如下：

sh
第1個元素為：1
第2個元素為：2
第3個元素為：3
slice 類型為[]i32
slice_2 類型為[]i32

創建切片的方式與訪問數組成員類似，但方括號 [] 中指定的是索引的邊界，遵循“左閉右開”原則。

在上面的例子中，我們從一個數組創建切片，其左邊界為 0，右邊界為變量 len。

注意：如果切片的兩個邊界值都是編譯期常量，編譯器會將其優化為數組指針；但如果至少有一個邊界值是運行時變量，那麼它就是一個真正的切片。

🅿️ 提示

切片的本質是一個“胖指針”（fat pointer），它內部包含一個 [*]T 類型的指針和一個長度值。

雖然 slice.ptr（指針）和 slice.len（長度）都是可以訪問和修改的，但在實踐中應避免直接操作它們，因為這很容易破壞切片的內部結構，導致不可預期的行為（除非你完全清楚自己在做什麼）。

切片指針 ​

切片除了有 len 屬性，還有一個 ptr 屬性，它是一個指向切片數據起始位置的多項指針。我們可以通過 slice.ptr 來訪問它。

當我們對切片中的單個元素取地址（&）時，會得到一個單項指針。

需要注意的是：直接對切片進行索引操作會進行邊界檢查，而通過 slice.ptr 對指針進行操作則不會有邊界檢查，需要開發者自行確保安全。

zig
var array = [_]i32{ 1, 2, 3, 4 };

// 边界使用变量，保证切片不会被优化为数组指针
var len: usize = 3;
_ = &len;

var slice = array[0..len];

print("slice 类型为{}\n", .{@TypeOf(slice)});
print("slice.ptr 类型为{}\n", .{@TypeOf(slice.ptr)});
print("slice 的索引 0 取地址，得到指针类型为{}\n", .{@TypeOf(&slice[0])});
zig
const print = @import("std").debug.print;

pub fn main() void {
    var array = [_]i32{ 1, 2, 3, 4 };

    // 边界使用变量，保证切片不会被优化为数组指针
    var len: usize = 3;
    _ = &len;

    var slice = array[0..len];

    print("slice 类型为{}\n", .{@TypeOf(slice)});
    print("slice.ptr 类型为{}\n", .{@TypeOf(slice.ptr)});
    print("slice 的索引 0 取地址，得到指针类型为{}\n", .{@TypeOf(&slice[0])});
}

打印結果如下：

sh
slice 類型為[]i32
slice.ptr 類型為[*]i32
slice 的索引 0 取地址，得到指針類型為*i32

哨兵切片（標記終止切片） ​

語法 [:x]T 定義了一個哨兵切片。它與普通切片類似，長度在運行時確定，但額外保證在索引 len 處存在一個值為 x 的哨兵元素。該類型不保證哨兵值不會出現在切片內容中。哨兵切片允許訪問索引為 len 的元素（即哨兵本身）。

我們也可以通過 data[start..end :x] 語法從多項指針、數組或普通切片中創建一個哨兵切片，其中 x 是哨兵值。

創建哨兵切片時，Zig 會假定在哨兵位置（即 end 索引處）的元素值就是指定的哨兵值。如果實際情況並非如此，將會觸發安全保護機制並導致未定義行為。

zig
// 显式声明切片类型
const str_slice: [:0]const u8 = "hello";
print("str_slice类型：{}\n", .{@TypeOf(str_slice)});

var array = [_]u8{ 3, 2, 1, 0, 3, 2, 1, 0 };
const runtime_length: usize = 3;
const slice: [:0]u8 = array[0..runtime_length :0];
print("slice类型：{}\n", .{@TypeOf(slice)});
zig
const print = @import("std").debug.print;

pub fn main() void {
    // 显式声明切片类型
    const str_slice: [:0]const u8 = "hello";
    print("str_slice类型：{}\n", .{@TypeOf(str_slice)});

    var array = [_]u8{ 3, 2, 1, 0, 3, 2, 1, 0 };
    const runtime_length: usize = 3;
    const slice: [:0]u8 = array[0..runtime_length :0];
    print("slice类型：{}\n", .{@TypeOf(slice)});
}

打印結果如下：

sh
str_slice類型：[:0]const u8
slice類型：[:0]u8
