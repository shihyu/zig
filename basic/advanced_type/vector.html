向量 ​

向量（Vector）提供了一種對一組同類型（布爾、整型、浮點、指針）值進行並行操作的方法，它會盡可能利用 SIMD（單指令多數據）指令集。

向量類型通過內置函數 @Vector 創建。

基本使用 ​

向量支持與底層基本類型相同的內置運算符。這些操作都是按元素執行的，並返回一個與輸入向量長度相同的向量。支持的運算符包括：

  • 算術運算符 (+, -, /, *, @divFloor, @sqrt, @ceil, @log, ... )
  • 位操作符 (>>, <<, &, |,~, ... )
  • 比較運算符 (<, >, ==, ...)

禁止混合使用標量（單個數字）和向量進行數學運算。Zig 提供了 @splat 內建函數，可以方便地將標量轉換為向量。同時，可以使用 @reduce 和數組索引語法將向量轉換為標量。向量還支持直接賦值給已知長度的固定長度數組。如果需要重新排列元素，可以使用 @shuffle 和 @select 函數。

zig
const std = @import("std");
const print = std.debug.print;

pub fn main() void {
    const ele_4 = @Vector(4, i32);

    // 向量必须拥有编译期已知的长度和类型
    const a = ele_4{ 1, 2, 3, 4 };
    const b = ele_4{ 5, 6, 7, 8 };

    // 执行相加的操作
    const c = a + b;

    print("Vector c is {any}\n", .{c});
    // 以数组索引的语法来访问向量的元素
    print("the third element of Vector c is {}\n", .{c[2]});

    // 定义一个数组，注意我们这里使用的是浮点类型
    var arr1: [4]f32 = [_]f32{ 1.1, 3.2, 4.5, 5.6 };
    // 直接转换成为一个向量
    const vec: @Vector(4, f32) = arr1;

    print("Vector vec is {any}\n", .{vec});

    // 将一个切片转换为向量
    const vec2: @Vector(2, f32) = arr1[1..3].*;
    print("Vector vec2 is {any}\n", .{vec2});
}

🅿️ 提示

可以使用 @as 將向量強制轉換為數組。

如果向量的長度小於目標機器的 SIMD 寄存器寬度，操作通常會編譯為單個 SIMD 指令；如果向量長度更長，則會編譯為多個 SIMD 指令。

如果目標體系結構不支持 SIMD，編譯器將默認依次對每個向量元素進行操作。

Zig 支持最大 2^32 - 1 的向量長度。請注意，過長的向量長度（例如 2^20）可能會導致當前版本的 Zig 編譯器崩潰。

解構向量 ​

與數組類似，向量也可以被解構：

zig
const print = @import("std").debug.print;

pub fn unpack(x: @Vector(4, f32), y: @Vector(4, f32)) @Vector(4, f32) {
    const a, const c, _, _ = x;
    const b, const d, _, _ = y;
    return .{ a, b, c, d };
}

pub fn main() void {
    const x: @Vector(4, f32) = .{ 1.0, 2.0, 3.0, 4.0 };
    const y: @Vector(4, f32) = .{ 5.0, 6.0, 7.0, 8.0 };
    print("{}", .{unpack(x, y)});
}

@splat ​

@splat(scalar: anytype) anytype

生成一個向量，其所有元素都與傳入的 scalar 參數相同。向量的類型和長度由編譯器推斷。

zig
const scalar: u32 = 5;
const result: @Vector(4, u32) = @splat(scalar);

@reduce ​

@reduce(comptime op: std.builtin.ReduceOp, value: anytype) E

使用傳入的運算符對向量進行水平歸約（sequential horizontal reduction），最終得到一個標量。

zig
const V = @Vector(4, i32);
const value = V{ 1, -1, 1, -1 };

const result = value > @as(V, @splat(0));
// result 是 { true, false, true, false };

const is_all_true = @reduce(.And, result);
// is_all_true 是 false

🅿️ 提示

  1. 所有運算符均可用於整型。
  2. .And, .Or, .Xor 也可用於布爾類型。
  3. .Min, .Max, .Add, .Mul 還可用於浮點型。

注意：.Add 和 .Mul 在整型上的操作是**環繞（wrapping）**的。

@shuffle ​

zig
@shuffle(
    comptime E: type,
    a: @Vector(a_len, E),
    b: @Vector(b_len, E),
    comptime mask: @Vector(mask_len, i32)
) @Vector(mask_len, E)

根據掩碼 mask（一個向量），從向量 a 或向量 b 中選擇元素，組成一個新的向量。mask 的長度決定了返回向量的長度。mask 中的每個值逐個指定從 a 或 b 中選擇哪個元素：正數表示從 a 中選擇指定索引的元素（索引從 0 開始遞增），負數表示從 b 中選擇指定索引的元素（索引從 -1 開始遞減）。

🅿️ 提示

  • 建議對 b 中的索引使用 ~ 運算符，這樣兩個向量的索引都可以從 0 開始（例如，~@as(i32, 0) 結果為 -1）。
  • 如果 mask 中選擇的元素在 a 或 b 中是 undefined，則結果向量中對應的元素也將是 undefined。
  • mask 中的元素索引越界會導致編譯錯誤。
  • 如果 a 或 b 是 undefined，則其長度被視為與另一個非 undefined 向量的長度相同。如果 a 和 b 都是 undefined，@shuffle 將返回一個所有元素都是 undefined 的向量。
zig
const a = @Vector(7, u8){ 'o', 'l', 'h', 'e', 'r', 'z', 'w' };
const b = @Vector(4, u8){ 'w', 'd', '!', 'x' };

const mask1 = @Vector(5, i32){ 2, 3, 1, 1, 0 };
const res1: @Vector(5, u8) = @shuffle(u8, a, undefined, mask1);
// res1 的值是 hello

// Combining two vectors
const mask2 = @Vector(6, i32){ -1, 0, 4, 1, -2, -3 };
const res2: @Vector(6, u8) = @shuffle(u8, a, b, mask2);
// res2 的值是 world!

@select ​

zig
@select(
    comptime T: type,
    pred: @Vector(len, bool),
    a: @Vector(len, T),
    b: @Vector(len, T)
) @Vector(len, T)

根據 pred（一個布爾類型的向量），按元素從 a 或 b 中選擇值。如果 pred[i] 為 true，則結果向量中對應的元素為 a[i]；否則為 b[i]。

zig
const ele_4 = @Vector(4, i32);

// 向量必须拥有编译期已知的长度和类型
const a = ele_4{ 1, 2, 3, 4 };
const b = ele_4{ 5, 6, 7, 8 };

const pred = @Vector(4, bool){
    true,
    false,
    false,
    true,
};

const c = @select(i32, pred, a, b);
// c 是 { 1, 6, 7, 4 }
