defer ​

defer 將在當前作用域末尾執行表達式。

如果存在多個 defer，它們將會按照出棧方式執行。

zig
const std = @import("std");
const print = std.debug.print;

pub fn main() !void {
    defer print("exec third\n", .{});

    if (false) {
        defer print("will not exec\n", .{});
    }

    defer {
        print("exec second\n", .{});
    }
    defer {
        print("exec first\n", .{});
    }
}

defer 分別可以執行單個語句和一個塊，並且如果控制流不經過 defer，則不會執行。

對應 defer 的還有 errdefer，具體見這裡 errdefer。
