循環 ​

在 zig 中，循環分為兩種，一種是 while，一種是 for。

for ​

for 循環是另一種循環處理方式，主要用於迭代數組和切片。

它支持 continue 和 break。

迭代數組和切片：

zig
const items = [_]i32{ 4, 5, 3, 4, 0 };
var sum: i32 = 0;

for (items) |value| {
    if (value == 0) {
        continue;
    }
    sum += value;
}

以上代碼中的 value，我們稱之為對 數組（切片）迭代的值捕獲，注意它是隻讀的。

在迭代時操作數組（切片）：

zig
var items = [_]i32{ 3, 4, 2 };

for (&items) |*value| {
    value.* += 1;
}

以上代碼中的 value 是一個指針，我們稱之為對 數組（切片）迭代的指針捕獲，注意它也是隻讀的，不過我們可以通過借引用指針來操作數組（切片）的值。

迭代數字 ​

迭代連續的整數很簡單，以下是示例：

zig
for (0..5) |i| {
    _ = i;
    // do something
}

迭代索引 ​

如果你想在迭代數組（切片）時，也可以訪問索引，可以這樣做：

zig
const items = [_]i32{ 4, 5, 3, 4, 0 };
for (items, 0..) |value, i| {
    _ = value;
    _ = i;
    // do something
}

以上代碼中，其中 value 是值，而 i 是索引。

多目標迭代 ​

當然，你也可以同時迭代多個目標（數組或切片）。需要注意的是，這些迭代目標的長度必須一致，以避免出現未定義行為。

zig
const items = [_]usize{ 1, 2, 3 };
const items2 = [_]usize{ 4, 5, 6 };

for (items, items2) |i, j| {
    _ = i;
    _ = j;
    // do something
}

作為表達式使用 ​

for 循環也可以作為表達式使用，其行為與 while 類似。

zig
const items = [_]?i32{ 3, 4, null, 5 };

const result = for (items) |value| {
    if (value == 5) {
        break value;
    }
} else 0;

標記 ​

continue 的效果類似於 goto，不推薦過度使用，因為它和 goto 一樣難以控制。在以下示例中，outer 是一個標籤。

break 的效果是在帶有標籤的循環處執行 break 操作。同樣，不推薦過度使用。

它們會增加代碼的複雜性，非必要不使用。

zig
var count: usize = 0;
outer: for (1..6) |_| {
    for (1..6) |_| {
        count += 1;
        break :outer;
    }
}
zig
var count: usize = 0;
outer: for (1..9) |_| {
    for (1..6) |_| {
        count += 1;
        continue :outer;
    }
}

內聯 inline ​

inline 關鍵字會將 for 循環展開，這使得代碼能夠執行一些僅在編譯時有效的操作。

需要注意的是，內聯 for 循環要求迭代的值和捕獲的值都必須在編譯期已知。

zig
pub fn main() !void {
    const nums = [_]i32{ 2, 4, 6 };
    var sum: usize = 0;
    inline for (nums) |i| {
        const T = switch (i) {
            2 => f32,
            4 => i8,
            6 => bool,
            else => unreachable,
        };
        sum += typeNameLength(T);
    }
    try expect(sum == 9);
}

fn typeNameLength(comptime T: type) usize {
    return @typeName(T).len;
}
zig
const std = @import("std");
const expect = std.testing.expect;

pub fn main() !void {
    const nums = [_]i32{ 2, 4, 6 };
    var sum: usize = 0;
    inline for (nums) |i| {
        const T = switch (i) {
            2 => f32,
            4 => i8,
            6 => bool,
            else => unreachable,
        };
        sum += typeNameLength(T);
    }
    try expect(sum == 9);
}

fn typeNameLength(comptime T: type) usize {
    return @typeName(T).len;
}

while ​

while 循環用於重複執行代碼塊，直到某個條件不再滿足。

基本使用：

zig
var i: usize = 0;
while (i < 10) {
    if (i == 5) {
        continue;
    }
    std.debug.print("i is {}\n", .{i});
    i += 1;
}
zig
const std = @import("std");

pub fn main() void {
    var i: usize = 0;
    while (i < 10) {
        if (i == 5) {
            continue;
        }
        std.debug.print("i is {}\n", .{i});
        i += 1;
    }

continue 表達式 ​

while 循環還支持一個被稱為 continue 表達式的機制，以便於我們控制循環。其內部可以是一個語句或一個代碼塊（由 {} 包裹）。

zig
var i: usize = 0;
while (i < 10) : (i += 1) {}
zig
var i: usize = 1;
var j: usize = 1;
while (i * j < 2000) : ({
    i *= 2;
    j *= 3;
}) {}

作為表達式使用 ​

Zig 還允許我們將 while 循環作為表達式使用，此時需要搭配 else 和 break 語句。

這裡的 else 分支會在 while 循環正常結束（即沒有通過 break 語句退出）時觸發。而 break 語句則類似於 return，可以在 while 循環內部返回值。

zig
fn rangeHasNumber(begin: usize, end: usize, number: usize) bool {
    var i = begin;
    return while (i < end) : (i += 1) {
        if (i == number) {
            break true;
        }
    } else false;
}

標記 ​

continue 的效果類似於 goto，不推薦過度使用，因為它和 goto 一樣難以控制。在以下示例中，outer 是一個標籤。

break 的效果是在帶有標籤的 while 循環處執行 break 操作。同樣，不推薦過度使用。

它們會增加代碼的複雜性，非必要不使用。

zig
var i: usize = 0;
outer: while (i < 10) : (i += 1) {
    while (true) {
        continue :outer;
    }
}
zig
outer: while (true) {
    while (true) {
        break :outer;
    }
}

內聯 inline ​

inline 關鍵字會將 while 循環展開，這使得代碼能夠執行一些僅在編譯時有效的操作。

zig
pub fn main() !void {
    comptime var i = 0;
    var sum: usize = 0;
    inline while (i < 3) : (i += 1) {
        const T = switch (i) {
            0 => f32,
            1 => i8,
            2 => bool,
            else => unreachable,
        };
        sum += typeNameLength(T);
    }
    try expect(sum == 9);
}

fn typeNameLength(comptime T: type) usize {
    return @typeName(T).len;
}
zig
const std = @import("std");
const expect = std.testing.expect;

pub fn main() !void {
    comptime var i = 0;
    var sum: usize = 0;
    inline while (i < 3) : (i += 1) {
        const T = switch (i) {
            0 => f32,
            1 => i8,
            2 => bool,
            else => unreachable,
        };
        sum += typeNameLength(T);
    }
    try expect(sum == 9);
}

fn typeNameLength(comptime T: type) usize {
    return @typeName(T).len;
}

🅿️ 提示

建議在以下情況使用內聯 while：

  • 需要在編譯期執行循環。
  • 你確定展開後代碼效率會更高。

解構可選類型 ​

與 if 類似，while 循環也會嘗試解構可選類型，並在遇到 null 時終止循環。

zig
while (eventuallyNullSequence()) |value| {
    sum2 += value;
} else {
    std.debug.print("meet a null\n", .{});
}
// 还可以使用else分支，碰到第一个 null 时触发并退出循环
zig
const std = @import("std");

var numbers_left: u32 = undefined;
fn eventuallyNullSequence() ?u32 {
    return if (numbers_left == 0) null else blk: {
        numbers_left -= 1;
        break :blk numbers_left;
    };
}

pub fn main() void {
    var sum2: u32 = 0;
    numbers_left = 3;
    while (eventuallyNullSequence()) |value| {
        sum2 += value;
    } else {
        std.debug.print("meet a null\n", .{});
    }
    // 还可以使用else分支，碰到第一个 null 时触发并退出循环
}

當 |x| 語法出現在 while 表達式中時，while 的條件必須是可選類型。

解構錯誤聯合類型 ​

與上述類似，while 循環也可以解構錯誤聯合類型。while 會分別捕獲錯誤和有效負載。當錯誤發生時，程序會轉到 else 分支執行，並退出循環：

zig
while (eventuallyErrorSequence()) |value| {
    sum1 += value;
} else |err| {
    std.debug.print("meet a err: {}\n", .{err});
}
zig
const std = @import("std");
var numbers_left: u32 = undefined;

fn eventuallyErrorSequence() anyerror!u32 {
    return if (numbers_left == 0) error.ReachedZero else blk: {
        numbers_left -= 1;
        break :blk numbers_left;
    };
}

pub fn main() void {
    var sum1: u32 = 0;
    numbers_left = 3;
    while (eventuallyErrorSequence()) |value| {
        sum1 += value;
    } else |err| {
        std.debug.print("meet a err: {}\n", .{err});
    }
}

當 else |x| 語法出現在 while 表達式中時，while 的條件必須是錯誤聯合類型。
