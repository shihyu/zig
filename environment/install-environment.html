環境安裝 ​

🅿️ 提示

當前 Zig 尚未發佈 1.0 版本，其發佈週期與 LLVM 的新版本發佈（約每 6 個月一次）相關聯。 因此，Zig 的穩定版發佈間隔較長。鑑於 Zig 的快速發展，穩定版可能很快會落後於最新功能，所以官方鼓勵用戶使用更新更頻繁的 nightly 版本。

Windows ​

windows 輸出中文亂碼問題

如果你是簡體中文用戶，建議將 Windows 的系統區域設置修改為 UTF-8。由於 Zig 源代碼及默認輸出使用 UTF-8 編碼，此舉可以避免在控制檯輸出中文時出現亂碼。

修改步驟如下：

  1. 打開 Windows 設置中的 時間和語言，進入 語言和區域。
  2. 點擊下方的管理語言設置，在新打開的窗口中點擊 管理。
  3. 點擊下方的 更改系統區域設置，勾選下方的“Beta: 使用 Unicode UTF-8 提供全球語言支持”。
  4. 重啟計算機。

Scoop ​

推薦使用 Scoop 工具進行安裝。Scoop 的 main 倉庫提供最新的 release 版本，而 versions 倉庫提供 nightly 版本。

安裝方式如下：

sh
scoop bucket add main
scoop install main/zig
sh
scoop bucket add versions
scoop install versions/zig-dev

🅿️ 提示

  • 使用 scoop reset zig-dev 或 scoop reset zig 可以在 nightly 和 release 版本之間切換。
  • 使用 scoop install zig@0.11.0 可以安裝特定版本，同理，scoop reset zig@0.11.0 可以切換到該指定版本。

其他的包管理器 ​

也可以使用諸如 WinGet 或 Chocolatey 等包管理器。

sh
winget install -e --id zig.zig
sh
choco install zig

手動安裝 ​

從官方 發佈頁面 下載對應的 Zig 版本，大多數用戶應選擇 zig-windows-x86_64。

解壓後，將包含 zig.exe 的目錄路徑添加到系統的 Path 環境變量中。可以通過以下 PowerShell 命令完成：

powershell
[Environment]::SetEnvironmentVariable(
   "Path",
   [Environment]::GetEnvironmentVariable("Path", "Machine")
   + ";C:\your-path\zig-windows-x86_64-your-version",
   "Machine"
)
powershell
[Environment]::SetEnvironmentVariable(
   "Path",
   [Environment]::GetEnvironmentVariable("Path", "User")
   + ";C:\your-path\zig-windows-x86_64-your-version",
   "User"
)

🅿️ 提示

System 對應系統全局環境變量，User 對應當前用戶環境變量。如果是個人電腦，兩者通常沒有太大區別。

請確保將 C:\your-path\zig-windows-x86_64-your-version 替換為你的實際解壓路徑。路徑前的分號 ; 是必需的，並非拼寫錯誤，它用於在 Path 變量中分隔多個路徑。

Mac ​

在 macOS 上安裝 Zig 非常方便。但若要使用 nightly 版本，仍需手動下載並設置環境變量。

sh
brew install zig
sh
port install zig

Linux ​

由於 Linux 發行版眾多，安裝方式各異。下面將先列出通過包管理器安裝的方法，然後說明手動安裝的步驟。

以下列出了支持通過包管理器安裝 Zig 的發行版和對應命令：

手動安裝 ​

從官方發佈頁面下載對應的 Zig 版本，解壓後將包含 Zig 二進制文件的目錄加入到 PATH 環境變量即可。

多版本管理 ​

由於 Zig 仍在快速迭代，使用新版 Zig 編譯器時，可能會遇到無法編譯舊有社區庫的問題。此時，除了向上遊社區尋求解決方案，更可靠的方式是使用特定版本的 Zig 來編譯特定項目。這就需要版本管理工具。

目前，Zig 的版本管理工具主要有以下幾個：

  • marler8997/zigup: Download and manage zig compilers
  • tristanisham/zvm: Lets you easily install/upgrade between different versions of Zig
  • hendriknielaender/zvm: Fast and simple zig version manager

讀者可根據需求自行選擇。本文將介紹一個通用的多語言版本管理工具：asdf。

  1. 請參考官方文檔 Getting Started 安裝 asdf。通常，可以通過 Homebrew (macOS) 或 apt (Debian/Ubuntu) 等包管理器直接安裝。
  2. 安裝 asdf Zig 插件：
bash
asdf plugin-add zig https://github.com/asdf-community/asdf-zig.git
  1. 安裝完成後，便可使用 asdf 管理 Zig 版本。以下是一些常用命令：
bash
# 列舉所有可安裝的版本
asdf list-all zig

# 安裝指定版本的 Zig
asdf install zig <version>

# 卸載指定版本的 Zig
asdf uninstall zig <version>

# 設置全局默認版本，會寫到 $HOME/.tool-versions 文件
asdf global zig <version>

# 設置當前目錄使用的版本，會寫到 $(pwd)/.tool-versions 文件
asdf local zig <version>
